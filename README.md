# unite-jobs

Shared architecture, development workflows, and agent instructions:
[UNITE project documentation](https://github.com/dkfz-unite/.github/blob/main/README.md).

Draft repository for a future shared task system. The owner plans to move the
complete task system here and give it a dedicated database.

Current application task entities and worker pipelines still use `unite-data`.
This draft is not an active replacement or part of the confirmed normal
platform deployment. The local workspace contains task data/context/migration
projects in progress; their presence does not establish a deployed integration.
